# Источники и память

Читай нужный раздел по текущему заданию. Наличие сервисов и схемы вызовов проверяй через доступные инструменты. Этот файл описывает поведение, не установку.

## Basic Memory и локальная база

Если Basic Memory доступен, выбери проект, связанный с заданием, найди предыдущие исследования и прочитай релевантные заметки с исходными ссылками. Не выбирай посторонний проект по умолчанию. Память указывает на доказательства; старый вывод не является новым подтверждением. Перепроверяй изменчивое.

При отсутствии памяти используй указанный пользователем каталог знаний и материалы текущего проекта. Не сканируй весь домашний каталог и чужие исследования. Базовый процесс работает без графовой базы.

В разрешённую базу сохраняй карточку с объектом, областью действия, датой проверки, утверждениями и их статусами, исходными ссылками, ссылкой на исследование, ограничениями и условием пересмотра. Решения сохраняй отдельно от фактов. Обновляй найденную карточку с сохранением истории; избегай дублей, проверяй запись чтением. При неопределённом месте или разрешении достаточно локальных итоговых файлов; не блокируй выдачу отчёта.

Переиспользуемые Markdown-заметки и MCP описаны в [Basic Memory](https://github.com/basicmachines-co/basic-memory). Локальное хранение файлов не означает локальность вызовов модели или коннекторов: соблюдай фактические границы доступа пользователя.

## PDF и Zotero

Для PDF сначала используй локальный MCP `markitdown` и `convert_to_markdown`, если доступны. Локальный путь передавай как file: URI, например через `Path(...).resolve().as_uri()`. Конвертация и OCR должны оставаться локальными; внешний сервис или модель для конвертации допустимы только по явному запросу пользователя.

Для PDF по URL сначала получи разрешённую локальную копию штатным способом. Невозможность скачивания — пробел доступа, не основание отправить файл в облачный конвертер. При необходимости проверь страницы локальным рендерером: таблицы, колонки и нумерация могут потеряться. Не выдумывай номер страницы; при отсутствии точной привязки укажи раздел и ограничение.

При подключённом Zotero MCP используй поиск библиотеки, метаданные, доступный полный текст и аннотации. Сохраняй идентификатор/ссылку записи и местоположение подтверждения. Чтение библиотеки не разрешает импорт, удаление и изменение записей; выполняй их только в рамках поручения. Zotero необязателен.

## Корпоративные источники

Для корпоративных источников используй подключённые инструменты и правила конкретного проекта. Не передавай внешнему поиску внутренние тексты и закрытые URL. Учитывай доступность ссылок адресату отчёта.

Исследование не разрешает сообщения коллегам и публикацию комментариев. Выполняй такие действия только по явному поручению пользователя и соблюдай установленные им правила публикации.

## Делегирование при отдельном разрешении

Выделяй независимые объекты с единым контрактом критериев и доказательств. Каждый исполнитель пишет в свою папку; общий писатель таблиц — один. Передавай ограничения, дату актуальности, ID и формат результата. При слиянии назначай уникальные ID источников и доказательств, переноси связанные ссылки, проверяй результат. Используй небольшой параллелизм в пределах среды и бюджета и один механизм координации одной матрицы.
