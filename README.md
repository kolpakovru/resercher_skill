# Researcher Skill

Скилл для Codex и других агентов, поддерживающих `SKILL.md`: исследования и сравнения с планом, матрицей критериев, источниками и доказательствами. Состояние сохраняется в файлах, чтобы работу можно было продолжить в следующей сессии.

Имя репозитория — `resercher_skill`, имя скилла для вызова — `researcher`.

## Возможности

- Начать исследование, продолжить его или расширить список объектов и критериев.
- Сохранять источники, утверждения и результаты сравнения с устойчивыми идентификаторами.
- Различать подтверждённые сведения, заявления поставщика, расчёты, предположения и неизвестное.
- Проверять полноту матрицы, связи между файлами и зависимости доказательств.
- Подготовить отчёт с прямыми ссылками и отдельно зафиксировать решение пользователя.

## Установка в Codex

Попросите Codex:

> Установи глобально скилл researcher из репозитория https://github.com/kolpakovru/resercher_skill, папка skills/researcher.

Для ручной установки клонируйте репозиторий и скопируйте папку `skills/researcher` в `$CODEX_HOME/skills/`. Если `CODEX_HOME` не задан, используйте `~/.codex/skills/`. Если скилл уже установлен, сначала сравните версии и сохраните локальные изменения.

Для установки только в отдельный проект поместите эту папку в `.agents/skills/researcher/` проекта. После установки начните новую сессию агента.

## Использование

Примеры запросов:

```text
Используй $researcher: сравни три платформы для нашей задачи.
Сначала зафиксируй ограничения, объекты и критерии выбора.

Используй $researcher: продолжи исследование в research/2026-11-08-platforms.

Используй $researcher: добавь два новых варианта в существующую матрицу,
сохрани прежние ID и перепроверь затронутые выводы.
```

Для одного справочного вопроса полный процесс не требуется. Если нужно сначала согласовать план, укажите это в запросе; также действуют правила согласования вашей среды и проекта.

## Вспомогательный скрипт

Нужен Python 3.10 или новее. Скрипт использует только стандартную библиотеку; сторонние Python-пакеты не нужны. Команды ниже выполняются из корня клонированного репозитория:

```sh
python skills/researcher/scripts/research.py init research/example --title "Сравнение платформ" --question "Какой вариант соответствует требованиям?"
python skills/researcher/scripts/research.py check research/example
python skills/researcher/scripts/research.py check research/example --final
```

`init` создаёт десять файлов и отказывается перезаписывать существующую папку. Обычная проверка допускает незавершённое исследование и сообщает о пробелах. `--final` дополнительно требует полного покрытия матрицы, разрешения обязательных критериев и заполненного отчёта.

Коды завершения: `0` — структурных ошибок нет, `1` — ошибки исследования, `2` — ошибка запуска. Проверка не доказывает истинность фактов, актуальность источников или правильность формул — это отдельная работа исследователя.
